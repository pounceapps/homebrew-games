# PounceApps Games Homebrew Tap

Games by Steve Sparks for macOS, installed with [Homebrew](https://brew.sh). Free, signed and notarized, for Apple
silicon and Intel Macs with macOS 13 or later.

```sh
brew install --cask pounceapps/games/blackjack
brew install --cask pounceapps/games/hangman
brew install --cask pounceapps/games/adventure-house
brew install --cask pounceapps/games/santa-fe-trader
brew install --cask pounceapps/games/inside-the-mainframe
```

Or tap once and use the short names:

```sh
brew tap pounceapps/games
brew install --cask blackjack hangman adventure-house santa-fe-trader inside-the-mainframe
```

`brew upgrade --cask` gets new versions; `brew uninstall --cask <game>` removes one.

Every game also plays in the browser at [stevesparks.com/arcade](https://stevesparks.com/arcade). The Mac apps are
listed at [stevesparks.com/apps](https://stevesparks.com/apps). The DMGs the casks download live in
[pounceapps/downloads](https://github.com/pounceapps/downloads). PounceApps' other apps are in
[pounceapps/homebrew-tap](https://github.com/pounceapps/homebrew-tap).
